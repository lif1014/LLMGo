# LLMGo!

两个座位共用 Qwen3.5-4B 下中国象棋。红方和黑方各发各的请求，只能看见棋盘和已经落下的走法，看不见对方的思考。

## 网页在哪里

网页进程跑在这台 GPU 服务器上，不是另外部署到公网。浏览器打开的是这个进程的端口。

对局服务跑在 `g32`。最多 300 步。启动后：

- 人如果就在这台机器上，打开 `http://127.0.0.1:7860`
- 人在自己的电脑上，先做端口转发，再打开同一个地址：

```shell
ssh -L 7860:127.0.0.1:7860 <用户>@g32
```

服务监听 `0.0.0.0:7860`，同一内网也可以直接访问 `http://g32:7860`。不需要域名，也不需要把页面放到另一台 Web 服务器。结束后的对局列在页面下方，点开后可以用上一手、下一手或播放看棋盘和完整思考。默认最多 300 步。

## 启动

先看有没有空闲 GPU。当前 8 张 A800 都几乎占满时，不要启动 vLLM。

```shell
cd /home/test/test06/lyh/LLMGo!
bash scripts/run_web.sh
```

模型服务（需要一张至少空出约 20GB 的 GPU）：

```shell
bash scripts/serve_vllm.sh
```

镜像用的是本机 `vllm/vllm-openai:v0.20.1`，里面有 `qwen3_5`。`max-model-len` 是 16384。g84 上的 vLLM 0.11 和 `lyh/torch29-vllm012-cu128` 没有这个架构，不能用来跑 Qwen3.5-4B。

vLLM 还没起来时，网页里可以把后端选成「脚本试下」，先看棋盘、思考栏和诊断。

## 记录

每一局写在 `runs/<对局id>/`：

- `events.jsonl`：完整思考、正式输出、走法和错误，文本不裁短
- `summary.json`：这一局的首步合法率和错误类型
- `frames/` 和 `game.gif`：只有打开「保存录像」才有

网页下方同时显示本局诊断和全部对局汇总。
