# 网页与诊断记录

/rsi 和 / 是本pipeline的只读面板。旧的多棋种开局控制页面已删除；对局查看直接嵌入研究面板。

展示 working / best / recommended、当前研究假设、任务职责、Meta-Agent可见文字与工具、实际token usage、Executor查询次数/间隔/状态、Worker阶段、文件入口、实时棋盘、模型流式输出与工具/请求诊断。

“评测难度与胜负统计”区显示任务ID、平台ID、L档位、基线/候选用途、有效完成局数、学生视角胜和负、胜率与得分率。选中任务的Skill、depth、时间上限及计划局数直接读取该任务manifest，按每页64KiB、最多256KiB读取并缓存，不扫描原始token日志，不查询集群。L1实际是Skill -9，L2是Skill -5；研究轮次0、任务编号j000005、局号-00都不代表引擎难度0。下拉框和单局摘要也显示L档位。

胜率=胜/有效完成局，得分率=(胜+0.5和)/有效完成局。正式已收集统计优先，运行中对局仅作暂时统计；程序异常不计分，未开始或已清理的记录显示“—”，不伪装成0%。表格限最近30项任务，逐局统计复用当前范围的既有游戏摘要（本研究最近1000局或选中任务）；切换为单任务范围时，其他任务仅显示正式已收集结果。这次详情更新只改静态文件，刷新即可生效，无需停止Web或Controller。

棋局区沿用旧版三栏：左侧学生提示、思考与正式输出，中间单一棋盘、走子列表与播放控制，右侧本局摘要及折叠事件。支持上一手、下一手、播放/暂停、从头播放、手数滑块及点击走子；每个局面关联当时学生最近一手的输出。复盘时自动刷新仍可收集新事件，但不会改变选定对局或手数；“跟随最新对局”返回直播。范围可选本研究最近1000局或选中任务，即使当前任务正在训练，也能查看已有评测对局。

回放先按字节游标读取既有short_events，再从对应原始位置接续实时token；没有精简文件时兼容原始事件。旧精简格式缺失的裁判request提示/思考只按raw_ref定点读取有界前缀，不重写日志。每手保留有界文字与最近40条诊断，完整事件仍可按需分页查看；切换对局会清空旧输出并停止播放。

成绩矩阵按候选、player/model轨道与L1–L8展开；缺档标记部分测试，不显示完整总分。保存各档W/D/L与得分率。实测最佳只依完整player面板更新，不设晋级阈值；模型轨道独立显示。

Meta-Agent日志是协议实际提供的可见文字/摘要、命令与事件，不保证服务提供未公开的内部推理。Qwen可见reasoning/content逐块保存；受保护推理桥记录每次请求的prompt、原始响应、usage、结束原因、延迟、实际预算扣除，候选工具及后备记录标明origin。候选伪造的棋盘/结果事件被包为candidate_event，只有裁判能生成正式positions/results。

完整事件留在events.jsonl；short_events保留有界窗口，不能代替原始证据。模型请求由referee产生的token仅展示一次，候选重复转发的token保留为诊断事件，避免网页思考文字重复。

性能：3秒增量、最近80个事件卡、20k文字窗口、详情按展开读取、原文64KiB分页、后台页停止刷新；最近30任务和200条评测；不扫描全部训练rollouts，不在HTTP请求内启动模型/cctl。巨大日志仅点击时分页读取。完整历史仍在共享盘。

默认绑定0.0.0.0:7860，由平台自己的端口转发访问。此服务无独立认证，不应暴露为公共互联网端口；无需为了看面板运行GPU。

支持平台路径转发，例如 `/beijing/job/1309690/expose`（带或不带末尾斜杠）及其 `/rsi` 页面。页面根据浏览器地址确定服务基底，CSS、JavaScript、导航和API均走同一转发前缀，不请求Cybertron主站的 `/static` 或 `/api/rsi`。本机根路径访问同样有效。更新静态文件后刷新页面即可加载该路径修复，无需重启评测或升级campaign。

启动入口仍为 `bash '/user/lyh4170/LLMGo!/scripts/start_rsi.sh' --web`。更新Python网页接口后，已有Web进程需要单独重启才能加载新接口；启动器会复用已运行的服务。无需升级campaign或重启Controller、Executor、训练/评测任务。
